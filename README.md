# Bluecoins Extractor

A lightweight tool to parse and export transaction records from backup files generated by the **Bluecoins** mobile app.

---

## 🔍 How Do Bluecoins Backup Files Work?

Files with the `.fydb` extension (such as `bluecoins.fydb`) are standard **SQLite 3 databases**.

### Core Database Architecture:
* **`TRANSACTIONSTABLE`**: Stores records for all transactions (income, expenses, transfers, and initial account balances).
  * Transaction amounts (`amount`) are stored as integers multiplied by a factor of **1,000,000** (for example, `$1,000` is stored internally as `1000000000`).
  * The `deletedTransaction` column tracks whether a record is active (`6`) or in trash/deleted (`5`). The extractor automatically filters and includes only active records (`6`).
* **`ITEMTABLE`**: Names or concepts associated with transactions (e.g., *groceries*, *tuition fee*).
* **`CHILDCATEGORYTABLE` & `PARENTCATEGORYTABLE`**: Category and subcategory hierarchy.
* **`ACCOUNTSTABLE` & `ACCOUNTTYPETABLE`**: Account details (banks, credit cards, cash, liabilities) and their corresponding types.
* **`LABELSTABLE`**: Labels/tags associated with each transaction.

---

## 🚀 Requirements

* **Python 3** (pre-installed on macOS/Linux).
* **Zero external dependencies**: Uses only Python's built-in standard libraries (`sqlite3`, `csv`, and `argparse`).

---

## 💻 Usage

### 1. Default Quick Execution
The script automatically detects the most recent `.fydb` backup in the `backups/` directory and outputs `transacciones_bluecoins.csv`:

```bash
python3 extractor.py
```

### 2. Advanced Options

* **Specify custom input backup file:**
  ```bash
  python3 extractor.py -i backups/bluecoins.fydb
  ```

* **Specify custom output CSV filename:**
  ```bash
  python3 extractor.py -o my_transactions.csv
  ```

## 📊 Exported CSV Structure

| Column | Description |
|---|---|
| `id` | Unique transaction identifier in Bluecoins |
| `date` | Transaction date and time (`YYYY-MM-DD HH:MM:SS`) |
| `type` | Transaction type (`Gastos`, `Ingresos`, `Transferir`, `Nueva cuenta`) |
| `title` | Transaction title or payee item |
| `amount` | Normalized amount in original currency (divided by 1,000,000) |
| `currency` | Currency code (e.g., COP, USD) |
| `conversion_rate` | Foreign exchange rate |
| `parent_category` | Parent category name |
| `category` | Subcategory name |
| `account_type` | Account type (Credit Card, Bank, Cash, etc.) |
| `account` | Associated account name |
| `transfer_pair_account` | Destination / origin pair account (for transfers) |
| `status` | Reconciliation status (`Reconciled`, `Cleared`, `Uncleared`) |
| `labels` | Associated labels/tags separated by commas |
| `notes` | Transaction notes (truncated to the first 15 characters) |
